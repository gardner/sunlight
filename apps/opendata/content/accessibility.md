# Accessibility Statement

**The Sunlight Project** is committed to ensuring digital accessibility for people with disabilities.

We are continually improving the user experience for everyone, applying the relevant accessibility standards (WCAG 2.1 AA).

## Features

Our infrastructure is built with the following accessibility features:
- High-contrast color palettes (accessible text contrast).
- Clear, readable typography (Fira Sans).
- Keyboard-navigable components.
- Screen-reader friendly semantic HTML.

## Feedback

We welcome your feedback on the accessibility of our tools. If you encounter accessibility barriers, please let us know.
